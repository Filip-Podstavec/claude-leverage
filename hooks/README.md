# Hooks

Hooks are shell commands that execute automatically in response to Claude Code events - before or after tool calls, on session start, or on specific triggers. Use them to enforce project rules, run linters, or gate destructive operations.

## Install

Hooks are configured in your Claude Code `settings.json`, not copied as standalone files. Each `.md` file in this directory documents a hook pattern with the relevant config snippet ready to paste.
