# Skills

Skills are reusable capability modules that Claude Code can invoke during a session. They define specialized behavior, domain knowledge, or multi-step procedures.

## Install

```bash
# User scope
mkdir -p ~/.claude/skills
cp <skill-file>.md ~/.claude/skills/

# Project scope
mkdir -p .claude/skills
cp <skill-file>.md .claude/skills/
```
